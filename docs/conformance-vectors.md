# External Conformance Vectors

The basic face-turn cubie vectors in `tests/test_moves.py` are transcribed from Herbert
Kociemba's canonical `CubeDefs` definitions:

- Source: [CubeDefs.html](https://www.kociemba.org/math/CubeDefs.htm)
- Accessed: 2026-11-19
- Canonical declarations: corner and edge order at source lines 8-10
- Corner colors and facelets: source lines 29-36
- Basic corner moves U, R, F, D, L, B: source lines 44-51
- Basic edge moves U, R, F, D, L, B: source lines 59-60

The project uses the same positional convention: each vector entry describes the cubie
occupying that position after one clockwise quarter turn. Corner orientations use values
0, 1, and 2 modulo three; edge orientations use values 0 and 1 modulo two.

The vectors are intentionally literal test data rather than values generated by the
implementation under test. They currently cover all six clockwise base moves. Half turns
and inverse turns are additionally checked through move composition and inverse laws.

Phase 2 adds literal source-to-destination sticker cycles converted from Kociemba's
published `FaceletMove` pull tables. They cover U, R, F, D, L, and B and are exercised by
the separate sticker-cycle engine. A fixed 1,000-seed workload compares that engine with
the geometry engine after every intermediate move, not merely at the final state.
