# Roadmap

## Foundation — current

- Repository metadata, licensing, documentation, CI, and package boundaries
- Canonical cubie and facelet representations
- Complete face-move and notation support
- Structured physical-state validation

## Deterministic capability

- Define and test a `Solver` protocol
- Review and integrate a mature license-compatible deterministic solver
- Build an independent facelet-based solution verifier
- Provide stable Python and CLI APIs

## Agent integration

- Expose bounded, schema-first MCP tools
- Publish task-specific agent skills with adversarial evaluations
- Ensure all solve paths validate inputs and independently verify outputs

## Research

- Versioned valid, invalid, shallow, and fixed-seed scramble corpora
- Reproducible correctness and performance benchmark runner
- Environment and artifact provenance in every result

## Optional vision

- Calibrated six-face acquisition with confidence estimates
- Physical validation as a constraint for uncertain classifications
- Synthetic and real-image evaluation datasets

Custom search algorithms and pruning tables are intentionally deferred until research or
capability gaps justify maintaining them.
